craft/ 内置资产许可与出处说明
================================

本目录（assets/open-design/craft/）内的全部 .md 规则书，版权归属与许可如下。

出处
----

craft/ 内容来自 OpenDesign 仓库的 craft/ 目录：

    源仓库：open-design（v0.21.1）
    源路径：<open-design>/craft/*.md

OpenDesign 将其 craft/ 内容标注为改编自 MIT 许可的 refero_skill 项目
（见源仓库 craft/README.md 的 "Attribution" 一节，随本目录副本一并保留）：

    上游项目：refero_skill
    上游地址：https://github.com/referodesign/refero_skill
    版权归属：© Refero Design
    许可：MIT License
    改编说明：OpenDesign 团队为契合其内部风格、并把示例中的通用 Tailwind
              色值改为指向 OD 自身设计 token（var(--accent) 等）而作了编辑。

本副本（tiansupowers）为 OpenDesign craft/ 的**逐字复制**，未作二次改编。
若需将示例 token 落到天溯体系，映射关系见仓库根 README / 集成说明：
原型与实现都不填 `:root`、都不用自定义前缀变量，视觉一律来自组件库主题
（`--te-*` 由 ts-web-package 提供），实现侧用 `var(--te-*)` 或 Te 组件 props
——**不引入 `--accent`**。
